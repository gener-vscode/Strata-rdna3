# Strata-rdna3 memory investigation — state (2026-11-09 19:49 → 11-10 16:36 HKT)

Machine: RX 7900 XT (gfx1100, 19.98 GiB VRAM) + Ryzen 7 7800X3D, 46.43 GiB RAM.
Repo `/home/tommy/repo/Strata-rdna3`, HEAD `ce61f3b0`. Model `Qwen3.8-Flash-Next-UD-IQ2_XS`, 39.4 GiB experts. Engine md5 `fb975936515c` across every arm below.

## 1. Root cause (established, unchanged)

Fork RSS 38.47 GiB vs upstream 32.47 GiB. NOT `STRATA_RESIDENT_PIN`, NOT `--resident-budget-gib`. Cause = a bigger prefill chunk inflates the prompt path's lend region, and in resident RAM mode the lend region's experts are duplicated into RAM.

**The identity, verified to 0.02 GiB on four arms:**
```
resident complement = (39.4 GiB experts − GPU expert cache GiB) + lend region GiB
```
Mechanism: chunk buffers are linear in chunk (`Prefill::bytes_needed_impl`, `src/prefill/prefill.cpp:2717-2746`); they are **borrowed from the expert cache's top slots** (`generate.cpp:736-738`, `lend_slots` `:8001-8003`); in resident mode every borrowed slot's expert must also live in RAM (`src/core/expert_source.cpp` fork 3566-3599).

## 2. `--max-context` is nearly free in RAM (answered + `MAX-CONTEXT-SIZING.md`)

`--max-context` sizes buffers that live on the **GPU** (`cudaMalloc(&sbuf, session_bytes(g, o.max_context, …))`, `src/program/generate.cpp:5412`, repeated at `:5448`, `:5830`). Most layers are GDN (constant state). Expert cache takes leftover VRAM. So: more context → smaller GPU cache → bigger RAM complement, 1:1.

Rate: **9 MiB per 1000 tokens** (three pairs: 9.12 / 8.00 / 10.24). 160000 → 224000 costs **+0.56 GiB RAM** and 351 cache slots (0.57 GiB). Recommended. Native max 229346 gives nothing extra.

## 5. Conversation cache (`CONV-CACHE-SIZING.md`) — most recent question, answered

**`--conversation-cache-mib` is a TOTAL byte budget shared by all parked conversations, NOT per slot.**
```cpp
// generate.cpp:9993
ConversationCache conversations((size_t) o.conversation_cache_mib * 1024*1024,
                                (size_t) o.conversation_cache_slots, o.conversation_cache_min_tokens);
// conversation_cache.hpp:210-212, 236, 246
bool enabled() const { return budget_ != 0 && slots_ != 0; }
if (enabled() && candidate.bytes() <= budget_ - bytes_) reuse_ = std::move(candidate);
```
So `mib 1536 --slots 2` ≠ 2×1536; it is 1536 shared. `mib 1 / slots 1536` (user's first draft) is technically enabled but useless.

**Snapshot density: 16.19 KiB/token** (`1 819 200 856 B / 109 761 tokens`; logged park lines 1.73–1.99 GiB with `evictions=1…8` climbing while `parked` stayed 1 = paid park cost every turn and evicted its own work).

| parked | size | vs mib 1536 (1.50 GiB) |
|---|---|---|
| 80 000 tok | **1.23 GiB** | fits, 271 MiB headroom |
| 97 175 tok | 1.50 GiB | budget ceiling |
| 128 000 tok | **1.98 GiB** | **cannot park at all** |

Deciding code `make_room` (`conversation_cache.hpp:315-330`):
```cpp
while (!entries_.empty() && (entries_.size() >= slots_ || bytes_ > budget_ - held - incoming)) {
    if (!evict_oldest()) return false;
}
```
`put` refuses **before** evicting (`:422-426`): `if (!enabled() || held > budget_ || n > budget_ - held) return false;`

**Answered scenario — `slots 2` + `mib 1536`, park 80K, interleave "hello, how are you":** 80K parks (1 entry, 1.23 GiB); short request tests `1 >= 2` false and `1.23 > 1.50 − ε` false → **no eviction → 80K restorable ✅**. With `slots 1`: `1 >= 1` true → `evict_oldest()` takes the 80K conversation away. `min_tokens` defaults to **0 = park every conversation** (`generate.cpp:831`), so nothing protects it; engine default slots = 4 (`:826`). Comment at `:828-830`: *"Every parked conversation costs one of conversation_cache_slots whatever its length, so without it a client that interleaves short side requests with one long conversation evicts the long one (oldest first)."*

Box cannot afford parking now: auto sizing is `auto_conversation_cache_mib(available, min_free_mib)` with **floor 2560 MiB** (`generate.cpp:827`); 3.80 GiB available − 2.50 = **1.3 GiB usable < 1.9 GiB per snapshot**. Running config correctly has both at 0. If wanted later: drop chunk to `auto` (+1.75 GiB back) then `--conversation-cache-mib 2048 --conversation-cache-slots 2 --conversation-cache-min-tokens 8000`.
